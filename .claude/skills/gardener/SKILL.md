# gardener — 승급 + lint

`raw/` 의 증거를 읽어 `wiki/` 의 정제된 지식으로 올리고, 주기적으로 위키를 건강검진한다.

대상은 **이 레포**. vault 루트 = `wiki-vault/`, 이 문서의 경로는 전부 그 기준이다.
`engine/` 은 도구 자리라 승급·lint 대상이 **아니다**.

## 불변 원칙

- **raw 에 있는 것만.** 출처 없는 단정·환각 금지. 모든 주장에 `sources:`.
- **`sources` 는 누적.** 페이지를 병합·갱신할 때 기존 출처를 **교체하지 않는다.**
  계보가 끊기면 위키를 믿을 수 없다.
- **뒤집힌 주장은 삭제가 아니라 기록.** *"~였으나 YYYY-MM-DD 자료로 뒤집힘"* 으로 남긴다.
- ⭐ **무거운 근거는 `s3://` 키로 인용한다.** raw 의 md 정제본이 원본 PDF·xlsx 에서 왔다면
  (원본은 MinIO — `AGENTS.md`의 증거 보존 계약), `sources` 에 **md 경로 + `s3://…` 키를 함께** 적는다.
  로컬 경로·presigned URL 은 금지(썩는다).
  정제본이 *불완전*하다고 적혀 있으면(폰트 깨짐·표 뭉갬) 그 한계를 승급된 페이지에도 옮긴다.
- **새 지식은 `confidence: low|medium` 으로 시작.** 주인이 검토하기 전엔 확정으로 쓰지 않는다.
- **복사가 아니라 추출.** 메모·기사를 옮겨 담지 말고 그 안의 지식·판단을 뽑는다.
- **`나.md` 를 먼저 읽는다.** 무엇을 어디에 붙일지는 거기 적힌 주인의 맥락이 기준이다.
  비어 있으면 승급을 시작하기 전에 **`/wiki-seed` 를 먼저 권한다.**

## 승급 동선

1. **미승급 자료 확인** — `raw/` 를 `index.md` 와 대조.
2. **신호 추출** — 각 raw 에서 오래 갈 지식 단위를 뽑는다(한 줄 주장 + 근거 인용 + 출처 경로).
   **근거 인용이 없으면 버린다.** raw 의 `## 왜 남기나`(3문 답변)를 반드시 읽는다 —
   그게 주인의 관점이고 붙을 자리의 힌트다.
3. **라우팅** — 전부 `wiki/` 로 가고 **`tags` 로 구분**한다(폴더 X):
   - 지식·노하우·통찰 → `wiki/<slug>.md` (tags 기본)
   - 방향을 바꾸는 판단 → `tags: [결정]`, 본문에 날짜·대안·이유
   - 자주 바뀌는 현황(구독·자산·장비) → `tags: [대장]`, 1행 = 1항목
   - 기간 회고 → `tags: [회고]`
   - 단발 할일 → **승급 안 함**
   - **기존 문서 갱신 우선.** 새 페이지는 반복될 주제만.
4. **합성** — 타깃 문서를 append 가 아니라 **일관되게 재구성**(병합·중복흡수·요약 먼저).
   frontmatter 3필드(`updated`·`tags`·`sources`). 다른 페이지와 `[[링크]]` 로 잇는다.
5. **반영** — `python3 engine/scripts/build_index.py` → `log.md` 에
   `## [YYYY-MM-DD] ingest | <제목>` append → 경로 명시 add → commit.

## lint 동선 (`/gardener --lint`)

**먼저 기계 검사를 돌린다** — 확실한 것은 사람이 볼 필요가 없다:

```bash
python3 engine/scripts/wiki_lint.py          # 사람이 읽는 리포트
python3 engine/scripts/wiki_lint.py --json   # 에이전트용
```

기계가 잡는 것: 깨진 `[[링크]]` · 유입 링크 없는 고아 · frontmatter 누락 ·
`raw/` 수정(append-only 위반) · `index.md` 누락.

**그다음 판단이 필요한 것을 읽는다.** 읽기 전용이고, 고칠 것을 **찾아서 보고**한다 —
명백한 것만 고친다.

| # | 점검 | 방법 |
|---|---|---|
| 1 | 페이지 간 **모순** | 같은 주제 페이지들의 주장 대조. 자동 폐기 금지 — **충돌 의심으로 보고** |
| 2 | **낡은 주장** | 새 raw 가 뒤집은 옛 서술. §불변원칙대로 기록으로 남기고 갱신 |
| 3 | **빠진 페이지** | 여러 곳에서 언급되는데 자기 페이지가 없는 개념 |
| 4 | **누락 상호참조** | 이어졌어야 할 페이지끼리 안 이어짐 |
| 5 | **데이터 공백** | 검색 한 번이면 메울 구멍 → `gaps.md` 에 적재 |

> 이 다섯을 기계에 맡기지 않는 이유: 규칙으로 흉내내면 오탐이 나고,
> **오탐 한 번이면 리포트 전체를 안 보게 된다.**

결과를 `log.md` 에 `## [YYYY-MM-DD] lint | <요약>` 으로 append.

## 끝나면

승급 문서 목록(또는 lint 발견 목록)을 한 줄씩 보고. 주인이 확인해 맞으면 `confidence` 를 올린다.
