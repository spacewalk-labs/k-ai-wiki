# 옵시디언 연동 — 내 위키를 노트북·폰에서 읽기

> 🤖 **이 문서는 에이전트가 보고 실행하도록 썼습니다.** 사람이 해야 하는 곳(GUI 클릭)은
> **"사람이 할 것"** 이라고 표시해 두었습니다. 나머지는 에이전트가 끝냅니다.

## 0. 무엇을 세우나

위키는 홈서버에서 에이전트가 쓰고, 여러분은 노트북·폰에서 읽습니다. 그 사이를
**GitHub private 레포**가 잇습니다.

```text
                    GitHub (private)  ← 허브
                       ↑        ↓
              push │            │ pull
                   │            │
        홈서버 클론              노트북·폰 클론
     (에이전트가 씀)             (옵시디언이 읽음)
     Claude Code · MinIO         Obsidian
```

### 🔴 규칙 하나 — 옵시디언은 **읽는** 클라이언트입니다

**쓰기는 에이전트를 거칩니다.** 옵시디언에서 직접 고치고 push 하지 않습니다.

이유는 셋입니다.

1. 위키에는 지켜야 할 규약이 있습니다 — `sources` 누적, `raw/` 불변, `index.md` 는 생성물.
   손으로 고치면 그 규약을 조용히 어깁니다.
2. 두 곳에서 동시에 쓰면 충돌합니다. 충돌 해결은 옵시디언이 제일 못하는 일입니다.
3. 어차피 **여러분이 쓸 필요가 없는 것**이 이 위키의 설계입니다.

읽다가 고칠 것이 생기면 고치지 말고 **에이전트에게 말하세요.** 그게 이 위키를 쓰는 방식입니다.

## 1. 홈서버 — GitHub private 레포에 올리기

**아직 GitHub 에 안 올렸다면** 여기부터. 이미 올렸으면 2단계로.

```bash
cd <위키 폴더>              # 예: ~/my-wiki
git remote -v               # origin 이 이미 있으면 이 단계는 끝
```

없다면 만듭니다. `gh` 가 있으면 한 줄입니다.

```bash
gh repo create <내계정>/<내위키> --private --source=. --remote=origin --push
```

`gh` 가 없으면 GitHub 웹에서 **Private** 레포를 만든 뒤:

```bash
git remote add origin https://github.com/<내계정>/<내위키>.git
git push -u origin main
```

> 🔴 **반드시 Private.** 개인 위키에는 판단·금액·관계가 쌓입니다.
> 나중에 지워도 git 히스토리에는 남습니다.

**확인** — 아래가 `origin/main` 을 보여주면 됩니다.

```bash
git rev-parse --abbrev-ref --symbolic-full-name @{u}
```

## 2. 노트북 — 옵시디언 설치

**사람이 할 것**: <https://obsidian.md/download> 에서 내 OS 용을 받아 설치합니다.

| OS | 받는 것 |
|---|---|
| Windows | 설치 실행파일 |
| macOS | DMG (Universal — 인텔·애플실리콘 공용) |
| Linux | AppImage · Deb · Snap · Flatpak 중 하나 |

에이전트가 대신 깔 수 있는 경우:

```bash
# Linux (Debian·Ubuntu 계열, deb 를 받은 경우)
sudo apt install -y ./Obsidian-*.deb
# Linux (snap 이 있는 박스)
sudo snap install obsidian --classic
# macOS (Homebrew)
brew install --cask obsidian
```

> 💡 **옵시디언은 홈서버가 아니라 여러분이 보는 기기에 깝니다.** 홈서버는 화면이 없습니다.

---

## 3. 노트북 — 위키를 클론

```bash
cd ~            # 원하는 위치
git clone https://github.com/<내계정>/<내위키>.git my-wiki
```

private 레포라 인증을 묻습니다. 둘 중 하나로 합니다.

- **HTTPS + Personal Access Token** (간단, 폰에서도 같은 방법)
  GitHub → Settings → Developer settings → Personal access tokens.
  권한은 **contents 읽기**만 있으면 읽기 전용으로 충분합니다.
- **SSH 키** (데스크탑에서 편함. 단 **폰에서는 안 됩니다** — 5단계 참고)

**확인**

```bash
cd my-wiki && ls wiki-vault/     # 나.md · index.md · raw/ · wiki/ 가 보이면 성공
```

## 4. 옵시디언에서 열기 — ⚠️ **레포 루트가 아니라 `wiki-vault/`**

**사람이 할 것**: 옵시디언 → **Open folder as vault** → 클론한 폴더 안의 **`wiki-vault`** 를 고릅니다.

```text
my-wiki/            ← ❌ 여기를 고르지 마세요
└── wiki-vault/     ← ✅ 여기입니다
```

레포 루트를 고르면 `engine/` 의 스크립트와 `.claude/` 의 스킬 파일이 검색·그래프·`[[링크]]`
자동완성에 전부 섞입니다. 이 위키가 도구를 vault **밖**에 둔 이유가 그것입니다.

> `.obsidian/` 폴더(옵시디언 설정)는 `.gitignore` 에 들어 있습니다. **기기마다 설정이 따로**
> 노는 게 맞습니다 — 노트북과 폰의 화면 크기·플러그인이 다르니까요.

**확인**: 왼쪽 파일 목록에 `나.md` 가 보이고, 열었을 때 `[[링크]]` 가 파랗게 잡히면 됩니다.

## 5. 최신으로 유지하기

### 기본 (권장) — `git pull` 만

가장 단순하고 어디서나 똑같이 동작합니다. 옵시디언을 켜기 전에 한 줄:

```bash
git -C ~/my-wiki pull --ff-only
```

에이전트에게 **"위키 최신으로 받아줘"** 라고 해도 됩니다.

자동으로 받고 싶으면 타이머 한 줄이면 됩니다.

```bash
# 30분마다 pull (Linux·macOS)
( crontab -l 2>/dev/null; echo "*/30 * * * * git -C $HOME/my-wiki pull --ff-only -q" ) | crontab -
```

> 📌 **vault 는 `wiki-vault/` 인데 pull 은 그 위(레포 루트)에서 합니다.**
> `wiki-vault/` 안에서 실행해도 git 이 알아서 레포 루트를 찾아 올라가므로 동작은 같습니다.

### 선택 — Obsidian Git 플러그인

옵시디언 안에서 자동으로 받고 싶을 때만 씁니다.

**사람이 할 것**: 설정 → **Community plugins** → Browse → **Git** (Vinzent03) → Install → Enable.

그다음 플러그인 설정에서 **읽기 전용으로** 맞춥니다(설정 이름은 그대로입니다).

| 설정 | 값 | 왜 |
|---|---|---|
| **Auto pull interval (minutes)** | `30` | 30분마다 받아옵니다 |
| **Pull on startup** | 켬 | 옵시디언을 켜면 먼저 받습니다 |
| **Auto commit-and-sync interval (minutes)** | `0` (끔) | 🔴 **옵시디언이 쓰지 않게 합니다** |
| **Push on commit-and-sync** | 끔 | 같은 이유 |

> 🔴 **자동 commit·push 를 켜지 마세요.** 이 문서 맨 위의 규칙이 무너집니다 —
> 에이전트가 쓰는 위키에 옵시디언이 끼어들어 충돌을 만듭니다.

플러그인이 레포를 못 찾는다고 하면, vault(`wiki-vault/`)가 레포 루트보다 아래라서 그렇습니다.
그때는 플러그인을 끄고 위의 **기본(`git pull`)** 방식으로 가세요 — 잃는 것이 없습니다.

### 폰 (iOS · Android)

**되긴 하지만 각오하고 쓰세요.** 공식 문서가 밝힌 제약입니다.

- **SSH 인증이 안 됩니다.** HTTPS + Personal Access Token 만 됩니다.
- 폰은 진짜 git 을 못 돌려서 **자바스크립트로 다시 구현한 git**(isomorphic-git)을 씁니다.
  그래서 레포가 커지면 **클론·pull 중에 옵시디언이 죽거나** 끝나지 않을 수 있습니다.
- rebase 병합·서브모듈이 안 됩니다.

**권합니다**: 폰에서는 **읽기만** 하세요. 위키가 커진 뒤 폰이 버거워지면, 폰의 git 연동은
포기하고 필요한 문서만 링크로 보는 편이 낫습니다 — 어차피 쓰기는 에이전트가 합니다.

## 6. 막히는 곳

| 증상 | 원인·해결 |
|---|---|
| 옵시디언에 `engine/`·`README.md` 가 보임 | vault 를 레포 루트로 열었습니다. 4단계대로 `wiki-vault/` 를 다시 여세요 |
| `git pull` 이 `Your local changes would be overwritten` | 옵시디언에서 뭔가 고쳤습니다. **에이전트에게 그 사실을 말하고** 처리를 맡기세요 |
| private 레포 클론이 인증 실패 | 3단계의 PAT 를 만들었는지, 유효기간이 남았는지 확인 |
| 폰에서 클론하다 앱이 죽음 | 위 "폰" 절의 알려진 제약입니다. 폰 git 연동은 포기해도 됩니다 |
| 새 문서가 옵시디언에 안 보임 | 아직 안 받았습니다 — `git pull` |

## 7. 에이전트에게 시킬 때

이 문서를 그대로 주고 이렇게 말하면 됩니다.

> "이 문서대로 내 노트북에 옵시디언 연동해 줘. GUI 로 눌러야 하는 건 나한테 알려 줘."

에이전트가 할 수 있는 것: GitHub private 레포 만들기·push · 옵시디언 설치(패키지 매니저가 있을 때) ·
클론 · 인증 설정 · pull 타이머 걸기 · 각 단계 확인.
사람이 해야 하는 것: 옵시디언에서 **vault 폴더 고르기**, 플러그인 설치·설정 토글(쓴다면).
